# Video Transition Studio
<img width="1126" height="773" alt="gambar" src="https://github.com/user-attachments/assets/b8a24e0b-c45c-4dff-8bb2-7816dadd81a8" />

Batch video transition studio untuk Windows — transisi matte brush dan watercolor, serta transisi 2D: Wipe, Split, Dissolve, Checkerboard, Blinds, Clock, Smooth Fade, Cut, plus animasi Zoom (Ken Burns) yang bisa aktif bersamaan dengan transisi.

## Features

- **Matte transition** — Brush Stroke & Watercolor 
- **2D transitions** — Wipe, Split, Dissolve, Checkerboard, Blinds, Clock.
- **Zoom (Ken Burns)** terpisah — Zoom In / Zoom Out halus.
- **Background** — solid color atau gambar custom.
- **Resolusi 720p / 1080p**

## Quick start

1. Install aplikasi
2. Tambah Video / Gambar / Folder, centang item.
3. Atur **Transisi** (Brush/Watercolor/Wipe/…) + **Animasi** (Tidak ada/Zoom In/Zoom Out + rasio), Latar, dan Resolusi.
4. Pilih Folder Output (pastikan berbeda dari folder input), lalu **Mulai Proses Batch**.
